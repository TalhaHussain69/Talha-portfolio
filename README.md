The portfolio uses a **dark futuristic aesthetic with teal/cyan accents**, combined with clean typography, subtle borders and interactive animations.

```text
Primary Style       → Futuristic / Premium / Minimal
Accent              → Teal / Cyan
Background          → Deep Dark

Interactions        → Smooth & Subtle
Responsive          → Mobile / Tablet / Desktop
```

The goal was to create a design that feels **professional without becoming unnecessarily crowded or over-designed**.
