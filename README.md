## 🎨 Design

The portfolio follows a **minimal futuristic visual language** rather than a traditional template.

### Visual Direction

- Primary accent: **Teal**
- Dark background: deep black/teal tones
- Light mode: clean off-white/teal tones
- Minimal borders
- Subtle animations
- Clean typography
- Responsive spacing
- No excessive cards or heavy shadows
- Interactive hover and fill effects

The goal is to keep the interface **premium, modern and visually memorable without becoming cluttered**.
